# OceanAnalysis

`OceanAnalysis` is a Julia package designed to facilitate the analysis of
oceanographic data. It is at an early stage of development, so there are are
sometimes breaking changes between versions. The largest of these occurred in
late September of 2026, when the package switched from using the `Plots`
graphical system to the more flexible and powerful `Makie` system.

All functions in the package are documented, although more work needs to be
done for some functions. Significant changes to functions are typically
reflected in items (open or closed) on the "Issues"" section of the development
website (see
[https://github.com/dankelley/OceanAnalysis.jl/issues](https://github.com/dankelley/OceanAnalysis.jl/issues)).

The online documentation is broken down as follows.

- Home: what you're reading now.
- [Installation](https://dankelley.github.io/OceanAnalysis.jl/dev/installation/): how to install `OceanAnalysis`.
- [Examples](https://dankelley.github.io/OceanAnalysis.jl/dev/examples/): some examples of common `OceanAnalysis` usage.
- [Data Types](https://dankelley.github.io/OceanAnalysis.jl/dev/data_types/): data types used by `OceanAnalyis`.
- [Functions](https://dankelley.github.io/OceanAnalysis.jl/dev/functions/): functions provided in `OceanAnalyis`.
- [Changelog](https://dankelley.github.io/OceanAnalysis.jl/dev/changelog/): changes made to `OceanAnalysis` over time.
- [Developer Notes](https://dankelley.github.io/OceanAnalysis.jl/dev/developer_notes/): some development notes.
